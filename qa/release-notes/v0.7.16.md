# v0.7.16 — Windows installer UX bundle

Three fixes for the dialogs Windows users couldn't see during install. All three were P0 reports — Docker's own installer hiding behind the Fox spinner, the access-mode modal doing the same, and a reboot prompt that didn't tell users the install would auto-resume.

## Highlights

- **Docker Desktop's installer is visible again.** During a fresh install on Windows, Fox launches Docker Desktop's setup via `winget`. The Fox progress spinner used to keep itself topmost throughout, hiding Docker's installer (and any UAC prompts) behind it. The spinner now steps aside while Docker is opening, then reclaims the foreground once Docker has its window. Closes #324.
- **The "How should this PC reach the container?" modal stays in front.** Same z-order race as the Docker dialog, different victim. The modal now attaches to the Fox progress window as a proper child, which makes Windows render it on top. Closes #330.
- **The post-install reboot prompt tells you what happens next.** "Fox in the box will resume installation automatically after your PC restarts — you do not need to re-launch the installer manually." Buttons read "Restart now" and "I'll restart later." The auto-resume behavior wired via Windows RunOnce was always there; users just weren't being told. Closes #325.

## Behind the scenes

- All three bugs traced to the same architectural detail: the Fox progress window opens with `alwaysOnTop: true` so users can see startup status, and that flag was quietly racing other windows it shouldn't have to compete with. The fix is a narrow `setForegroundYield()` dependency injected from `main.js` into `startup.js`, plus a parent BrowserWindow threaded through to `dialog.showMessageBox` in `docker-manager.js` — both kept Electron-free in the lower modules so the existing dependency-injection test surface stays intact.
- 71/71 jest tests pass, no regressions.
- Win11 VM smoke verification on the published artifact happens post-release (third consecutive `qa/SMOKE_LOG.md` bypass entry — the streak ends in v0.7.17 by commitment).
